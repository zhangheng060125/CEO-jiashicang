# 森活森动文旅集团 · CEO 经营驾驶舱

面向合肥市庐江县汤池镇温泉度假园区的中文经营系统。已实现「录入/导入 → SQLite 持久化 → 指标统计 → CEO 首页 → 原始订单下钻 → 异常指派、整改和复查」闭环。包含集团、单项目、独立运营公司视角。

## 启动

```bash
cd /workspace/CEO-jiashicang
bash scripts/setup.sh
bash scripts/start.sh
```

Python 3.12、Node.js（用于 JS 语法校验）。后端 FastAPI + SQLite；前端复用已有原生 HTML/CSS/JavaScript，无需前端打包。服务端口默认 **3001**，可通过 `PORT` 修改。安装脚本创建 `.runtime/venv`，复用符合固定版本的环境包，安装缺失依赖、初始化演示数据并运行测试。已有数据库不会被覆盖。

登录页可进入**独立演示空间**体验全部经营流程。真实空间首次启动创建 `admin` 账号，随机初始密码在服务器 `.runtime/admin-password.txt`，权限为 0600；不写入源代码或聊天。请由部署管理者安全交付给实际管理员，使用 `python scripts/reset_password.py` 修改后初始密码文件会删除。管理员可在左下角账号入口创建店长、财务和运营账号并指定项目范围。

数据库：`.runtime/hotel.sqlite3`（或 `HOTEL_DATA_DIR/hotel.sqlite3`）。数据存储在后端数据库，不依赖浏览器 localStorage。服务器仅提供明确列出的页面资源，不会通过HTTP暴露数据库、源码或凭据。

## 已交付模块（v1.2）

- **CEO 首页**：履约净收入、间夜、入住率、ADR、RevPAR、未来7/30天预订、获客后经营贡献、到账和待结算；同一查询返回指标及对应订单。
- **酒店与房态**：规划与物理房量、逐店逐日房型可售、停用、锁房、开放日历、工作日/周末/节假日与参考房价；未来7/30/90天确认预约与券承诺分开。
- **全渠道**：短视频、直播、达人、广告、OTA、小程序、私域记录；曝光、观看、有效咨询与订单支付/预约/退款/履约关联；自然和付费独立字段，首次/辅助/最终来源独立保留。
- **财务与运营公司**：订单、收款、退款、履约和到账分开；佣金按实际合同的期限、基数、比例与账期计算；园区收入不重复增加内部运营佣金。
- **餐饮与配套**：餐饮客群、人数及客单，明确分摊业务成本；季节营业日历、套餐权益、预售券/会员履约。代销商品本金单列应付款，仅净服务费计收入。
- **客户与服务**：匿名客户、新老客和已录入复购、响应时间、未成交原因；前台、客房、餐饮、清洁、厨房等检查/投诉台账，红线独立提示。
- **预算与预警**：预算/预测与实绩分开；预订不足、退款、超预算、成熟订单已知贡献为负、结算逾期、成本/房态缺失可生成整改任务；关闭需整改证据、复查人及结果。
- **数据中心**：全部类型手工新增、编辑、删除；CSV/XLSX模板、预览、校验、去重、原子导入、导入日志和修改前后审计；授权范围CSV导出。API执行角色和项目权限，客户端隐藏按钮不是唯一防线。

## 推荐使用顺序

1. 在真实数据空间确认各酒店/项目的开放状态、规划和物理房量，再录入逐日库存与实际营业日历。
2. 录入真实结算合同、营销活动、匿名客户；没有实际合同不预设合作年限或佣金。
3. 录入订单，再录入预约、每日履约权益、收退款和结算。跨夜住宿每晚分别记录，不把整单金额挤到入住日。退款可指定原履约外部编号；会员/券核销填写权益代码与份数。
4. 录入成本、活动获客费用，由财务完成逐日成本完整性确认；活动花费不要再重复录为营销成本。
5. 查看首页、下钻订单、创建问题并分派负责人和截止时间，整改后提交证据，由复查人填写结果再关闭。

数据类型与字段说明见 [导入字典](docs/import-schema.md)；全部模板在 [templates](templates/)，也可直接从页面下载。代码生成的演示数据只进入 `demo` 数据集，**真实空间只有用户已提供的集团项目背景，无虚构经营流水**。

## 经营功能补齐

- 可编辑预警阈值、负责人和期限；异常指派去重，关闭后再次触发有记录。
- 预算/预测逐项目与渠道实际差异、产品贡献和同批匿名观看客户转化。
- 定向权益退款、会员券核销及到期余额；平台扣款不重复计入收款或费用。
- SOP标准、检查、自动整改及口碑回复；红线不能直接删除或通过降级绕过复查。
- 自助密码修改、角色和范围调整、会话撤销；并发版本冲突保护。
- 独立目录恢复、新进程启动验收、可移植启动脚本。

## 接入与部署准备（v1.2）

- 数据中心新增「管理数据接入」：真实管理员按项目、业务类型和有效期授权适配程序，凭证仅展示一次；支持撤销与已验签批次日志。
- 自定义投递入口校验时间戳、签名和nonce；重复批次返回原结果、变更内容拒绝、错误整批回滚。提供 `scripts/adapter_push.py`，尚未连接任何第三方平台。
- `scripts/prepare_deployment.py` 生成生产环境变量、systemd服务、每日备份定时器和Nginx HTTPS配置，需确定服务器和域名后使用。
- `scripts/backup_daily.py` 生成并校验一致性备份；恢复时清理会话并撤销全部旧接入凭证。

完整要求对照见 [需求完成清单](docs/completion.md)。
