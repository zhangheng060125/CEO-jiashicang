# 实现自动采集，需要谁准备什么

目标不是让AI猜出所有数据，而是“业务系统自动同步 + 票据OCR辅助补录 + 缺失/异常人工处理”。实际入住、入园、食材耗用、人员出勤、银行到账必须在相应原系统或设备中留下记录，发票不能替代这些事实。

## 可以直接交给下属的任务表

| 负责人 | 先盘点的系统 | 交付给对接人员的内容 |
|---|---|---|
| 各酒店店长 | 当前或待采购的PMS、夜审、房态及门锁 | 系统名/版本、供应商联系人、门店编号、脱敏订单/夜审/房态样例、开放接口及历史回补能力 |
| 餐饮负责人 | POS收银、厨房/库存采购 | 账单及菜品明细、用餐人次、收费/赠送、开台、退菜和退款；期初/入库/期末/耗用/损耗记录及原始编号 |
| 游乐负责人 | 售票、闸机、核销、营业安排 | 票单/券及核销对应关系、实际入园与免费人次、真实营业日历、核准日接待上限、安全事件来源 |
| 温泉SPA负责人 | 预约、核销、工位/员工排班 | 同批预约与完成、服务人次、工位可售及占用分钟、实际工时及服务产品代码 |
| 财务负责人 | 银行、微信/支付宝商户、财务系统、工资及固定费用 | 可授权的流水/结算、平台扣费、费用归属、食材耗用口径、真实佣金合同、对账负责人及审批规则 |
| 线上运营负责人 | OTA、抖音、小红书、视频号、小程序/会员 | 企业/商家账户、可申请的API与服务商、曝光/咨询/订单/退款/核销字段和授权范围；无逐客事件就保留未知归因 |
| 一名集团数据负责人 | 门店和产品编码、接口运行与对账 | 统一门店/部门/产品/订单ID映射，更新频率、数据责任人、失败补传及每日对账规则 |

使用 [数据源盘点表](../templates/data-sources.csv) 填写系统和负责人信息；不要把密码、密钥或真实客户资料填进公开GitHub仓库或发送到聊天。

## 要向软件供应商问清楚的内容

1. 是否有正式开放API、Webhook或可自动投递的定时报表，接口说明、申请流程和费用是什么。
2. 是否能按本集团门店授权读取，是否允许取得逐笔及逐夜明细，而不仅是大屏合计。
3. 如何提供新增、变更、取消、退款、核销撤销和结算修正；是否有稳定原始ID、更新时间、翻页游标和历史回补。
4. 哪些字段无法提供，是否有限流、可用时间、数据保留期；授权失效如何通知和续期。
5. 没有API时，是否可定时输出脱敏CSV/XLSX到安全交接目录；仍需开发对应文件读取、签名投递和失败告警程序。

接口密钥在正式后台安全配置，由各企业/商家账户管理员办理授权。财务核对成本和交易口径；AI不会通过一个登录账号就自动获得所有平台权限。

## 实施步骤

1. **部署真实后台**：独立HTTPS地址、持久数据库与附件磁盘、人员和项目权限、备份、进程管理和监控。GitHub Pages只展示模拟数据，无法保存员工的真实上传。
2. **先打通一店PMS + POS + 财务**：供应商确定后编写对应适配程序。当前已有签名接入API、按项目/记录类型授权、批次去重、原子校验及日志；创建接入令牌不会自动安装供应商适配器。
3. **做字段映射和事实去重**：一笔订单统一ID，履约、收款、退款、结算分别记录；跨业态套餐明确分配。不可把PMS、OTA和支付平台同一笔金额各当一次收入。当前接口相同编号内容变化会拒绝静默覆盖，需要按实际版本设计受控更新或冲正流程。
4. **安排同步与异常处理**：订单/房态/核销可从5至15分钟同步起步，财务/库存日结；频率以供应商能力为准。补历史、处理迟到数据、取消/退款、断线重试、授权失效、重复投递和原始系统停机。
5. **补充票务、闸机、预约和运营数据**：先保证服务、库存和钱能对上，再连接流量分析。不支持开放接口的平台保留定时导入或人工核对，不宣称已经自动抓取。
6. **单店试运行对账再推广**：原系统日结、银行/支付、业务履约、费用与驾驶舱下钻逐一核对；覆盖取消、跨夜、套餐、部分退款、重复投递、停业日和佣金。确认后扩大到其他项目。

## AI可以承担的部分和仍需保留的人工工作

- 已实现：本机中文/英文OCR，读取照片/PDF/普通xlsx的金额、日期、商家、票号并给出分类建议；保存原件和识别建议，财务确认实际费用或仅分类归档。
- 需要额外选型配置才有：复杂/手写单据的大模型识别、更强语义分类、语音转写及后续分析代理。要确认供应商、处理地域/隐私、调用费用、密钥和错误处理，不应把这些能力标成已接通。现有录音仅留存回放。
- 必须留人工责任：未知或冲突数据核对、食材采购与耗用区别、共同费用分摊、费用确认、重大服务红线复查及原始凭证对账。没有传感器、工时或业务记录的数据无法仅靠AI可靠补全。

本次交付了各业务专业采集字段、页面、模板和接入任务清单；没有真实供应商授权，因此没有宣称PMS、POS、银行、OTA或闸机自动同步已上线。
