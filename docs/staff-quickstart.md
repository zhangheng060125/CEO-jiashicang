# 员工随手拍：只做三步

主管先帮员工登录一次，把入口放到手机桌面；员工不需要制作Excel。

1. **选大按钮**：📷「拍现场」上报问题；🧾「拍单据」上传发票或报销单。
2. **拍下来**：拍照、选已有文件，或录一句话。文字可以不填；一张单据一次提交，多页可一起选。
3. **点上传**：看到「已提交」即可离开。之后在记录里听或看主管反馈。

🎙 说不清、不会打字，可以录音补充；单据仍要拍一张照片。

🔊 看不清字，点「听怎么用」或「读给我听」。

📷 主管安排整改后，再点「提交整改照片 / 录音」，拍完成后的情况。

👤 完全不会用手机，可以请主管或班组数据员代拍代传，在录音里说明是谁的事项。系统会记录实际上传人。

拍票据只是提交资料，财务还要确认性质；它不代表已经付款或报销到账。

正式入口由主管提供。GitHub演示站只能看流程，不能上传真实单据。
